# Whisper Voice Typing for Linux

Это утилита для глобального голосового ввода на Linux (тестировалось на Linux Mint / Cinnamon / Ubuntu). Она работает в фоне, интегрируется в системный трей (System Tray) и позволяет диктовать текст в любое активное окно с помощью локальной нейросети **Whisper**.

## Главные фичи
- **100% Локально и Приватно.** Аудио никуда не отправляется, всё распознавание идёт на вашей видеокарте.
- **Push-to-Talk.** Запись активируется зажатием правого `Ctrl`.
- **Интеграция с Linux.** Пишет напрямую с системного микрофона через `parec`, нажимает кнопки за вас через `xdotool`.
- **Умная база истории.** Все ваши распознанные тексты сохраняются в локальную базу SQLite с поддержкой быстрого полнотекстового поиска (FTS5) — можно всегда найти, что вы надиктовали месяц назад.
- **Никаких заиканий интерфейса.** Графика висит в системном трее через GTK3, а прослушивание клавиатуры идёт асинхронно через ядро Linux (`/dev/input/eventX`).

## Как это выглядит
- Серая иконка микрофона в трее — статус ожидания.
- Зажали `Right Ctrl` — иконка загорелась красным, пошла запись.
- Отпустили — иконка пожелтела, аудио обрабатывается сервером и через пару секунд готовый текст вставляется в ваше активное окно.

## Ограничения и Совместимость
Скрипт использует легковесные системные утилиты, поэтому есть строгие системные требования:

- **Только X11.** Скрипт завязан на `xdotool` и `xclip` для вставки текста. На **Wayland** работать "из коробки" не будет (потребуется замена на `ydotool` и `wl-copy`).
- **Окружение (DE):** Разработано на GTK3 и `AyatanaAppIndicator3`. Отлично работает на **Cinnamon, XFCE, MATE** и **Ubuntu (GNOME с расширением AppIndicator)**. На чистом ванильном GNOME иконка трея может не появиться без установки дополнительных расширений трея.
- **Звук:** Требуется **PulseAudio** (или PipeWire с прослойкой `pipewire-pulse`), так как для записи звука используется утилита `parec`.
- **Чтение клавиатуры:** Для обхода проблем с глобальными хоткеями в X11 скрипт читает сырые события через `evtest` из `/dev/input/`. Именно поэтому строго необходимо добавить пользователя в группу `input`.

## Требования

- **Видеокарта NVIDIA** (желательно, для быстрой работы модели).
- Скомпилированный **whisper.cpp** (в виде `whisper-server`).
- Системные утилиты: `evtest`, `xdotool`, `xclip`, `pulseaudio-utils` (для parec).
- Python 3.

## Установка и запуск

1. Склонируйте этот репозиторий. (Он включает `whisper.cpp` как подмодуль).
   ```bash
   git clone --recursive https://github.com/k1paris/whisper-voice-typing.git
   cd whisper-voice-typing
   ```
2. Установите зависимости:
   ```bash
   sudo apt update
   sudo apt install evtest xdotool xclip pulseaudio-utils python3-gi gir1.2-gtk-3.0 gir1.2-ayatanaappindicator3-0.1
   ```
3. Добавьте своего пользователя в группу `input` (для чтения нажатий `Ctrl` в обход оконного менеджера):
   ```bash
   sudo usermod -aG input $USER
   ```
   *Перезагрузите ПК после этого, чтобы права применились.*
4. Скомпилируйте `whisper-server` с поддержкой вашей видеокарты (например, для NVIDIA CUDA):
   ```bash
   cd whisper.cpp
   cmake -B build -DGGML_CUDA=1
   cmake --build build --config Release -j
   cd ..
   ```
5. Скачайте желаемую модель Whisper. Для сложных задач и смешанной речи рекомендуется `large-v3-turbo` (если у вас >6GB видеопамяти), для быстрых ответов — `small`:
   ```bash
   cd whisper.cpp/models
   bash ./download-ggml-model.sh large-v3-turbo
   cd ../..
   ```
6. Отредактируйте конфигурацию в файле `app/config.py`, если вы скачали другую модель (по умолчанию прописана `ggml-large-v3-turbo.bin`).

**Запуск:**
```bash
python3 app/whisper_app.py
```
Программа свернётся в трей.

## Файловая структура
- `app/whisper_app.py` — Главный скрипт, рисует GTK иконку в трее и управляет процессом `whisper-server`.
- `app/input_listener.py` — Парсит сырые эвенты `/dev/input/` и ждёт нажатия Right Ctrl.
- `app/recorder.py` — Управляет записью звука через `parec` и отправкой аудио в Whisper.
- `app/history.py` — Логика SQLite базы данных и GTK-окно полнотекстового поиска истории.
